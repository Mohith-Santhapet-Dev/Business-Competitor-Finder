# 🔍 Business Competitor Finder

An AI-powered competitor analysis tool that helps entrepreneurs and business owners discover their competition before launching.

## Features
- 🏆 Finds 5-10 competitors based on your business idea and location
- 🔴 Threat scoring system that rates each competitor 1-10
- 🌍 Market gap analysis to identify opportunities
- 📥 Export results to CSV

## Built With
- Python
- Streamlit
- OpenAI API

## How to Run Locally
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Add your OpenAI API key to a `.env` file: `OPENAI_API_KEY=your-key-here`
4. Run the app: `streamlit run app.py`
